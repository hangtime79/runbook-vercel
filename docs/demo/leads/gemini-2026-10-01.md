# Leads from Gemini (2026-10-01): UNVERIFIED

These are what Gemini said when Grant asked about analyst views, strengths and weaknesses, competitor
attacks and Vercel's responses. **Nothing here is a source.** Each lead must be confirmed against a
primary source (an analyst page, Vercel docs or changelog, a competitor's own page) before it goes
into `objections-research.md`. The cited "sources" Gemini gave are mostly secondary: VibeEval,
TrueFoundry, FocusReactive, and an SEO page titled "Software Problems & Issues Exposed 2026".

## Analysts
- L-01 Gartner named Vercel a "Visionary" in the 2024 Magic Quadrant for Cloud Application Platforms.
- L-02 Gartner Peer Insights: praise for DX, previews, edge autoscaling; complaints about debugging
  (abstracted infra), unpredictable scaling costs, slow builds on very large apps.
- L-03 Forrester Wave: Edge Development Platforms, Q4 2023, included Vercel.
- L-04 Forrester note, April 2026, "Game Over For Trust": a supply-chain incident involving a
  third-party integration on Vercel; rapid-deploy platforms strain shared-responsibility models.
  (Cited via VibeEval.) **Highest priority: if Vercel had a 2026 security incident, a bank CIO will know.**
- L-05 TrueFoundry: the AI SDK is the default for GenAI web UIs; about 10 ms edge latency; limits are
  a 5-minute timeout on Pro, a 4.5 MB payload and no GPUs; pair with containers for heavy backends.

## Strengths claimed
- L-06 Push-to-deploy, Git integrations, framework detection, instant rollback.
- L-07 A preview URL per PR; comments on previews.
- L-08 Edge security: L3/L4/L7 DDoS mitigation, TLS 1.3, AI-bot filtering (GPTBot, ClaudeBot).

## Weaknesses claimed
- L-09 Bandwidth overage of about $150/TB (= $0.15/GB) vs CloudFront; $20 per seat compounds.
- L-10 "Black box" debugging of build and runtime errors.
- L-11 No long-running workers (only `waitUntil`), no persistent databases, "frontend only".
- L-12 Automated suspensions on traffic spikes or billing anomalies; slow support below Enterprise.

## Competitor attacks
- L-13 Cloudflare: zero egress fees; a native edge network; D1, edge AI.
- L-14 Netlify: framework-agnostic; Next.js lock-in; built-in forms, identity, split testing.
- L-15 AWS: no custom VPC deployment; TCO flips at scale; OpenNext or Amplify avoids the "Vercel tax".
- L-16 Render, Railway, Northflank: no managed DB, no persistent workers, **no WebSockets**,
  timeouts; they run Docker, GPUs and cron.

## Vercel's responses (as Gemini describes them)
- L-17 Active CPU billing: I/O wait is not billed.
- L-18 Fluid compute: full Node.js, Python and Go, vs V8 isolates.
- L-19 Framework-defined infrastructure: "Infrastructure as Code, without the YAML".
- L-20 Next.js day-one features (RSC, PPR, cache tags) that others reverse-engineer.
- L-21 TCO is labour, not compute: the DevOps tax.
- L-22 `waitUntil` softens the background-work limits.
- L-23 AI SDK as the standard; v0; preview comments.

## Known problems with these leads (from what this repo already records)
- "Frontend Cloud" is old positioning. The script says the current tagline is "Agentic Infrastructure".
- The Edge runtime is deprecated in favour of Node.js on Fluid compute, so "edge functions" framing is dated.
- L-16 "no WebSockets" and L-11 "no long-running workers" look out of date. Vercel Functions now
  support WebSockets, and Workflow, Queues and Sandbox exist. Verify each before using it.
- L-15 "no custom VPC": Enterprise **Secure Compute** (dedicated VPC, peering, VPN) is already in
  `demo-script.md`. Answer with the tier.
- L-05 "5 minutes on Pro": 300 s is now the *default* on all plans. Check the Pro maximum.
