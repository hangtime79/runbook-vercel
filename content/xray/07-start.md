## Tell
This app is the prop. It is an investigator-style app: an analysis turned into a tool, built by coding agents from a written runbook. Tell them that; it's the whole point.


## On Vercel
This app is a standard Next.js app on Vercel Functions (Fluid compute) with the AI SDK and AI Gateway, built by coding agents from a runbook. For the bank: standard Node and Next.js, and the gateway works from any environment, so the app is not welded to the platform; Connect is the one Vercel-only piece. *Sources: vercel-positioning.md §3 and §6, "Lock-in".*
